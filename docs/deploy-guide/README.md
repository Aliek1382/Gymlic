# راهنمای استقرار — نسخه‌ی PDF

`gymlic-deploy-guide.pdf` نسخه‌ی قابل چاپ و آفلاین همان چیزی است که در
`README.md` ریشه‌ی مخزن نوشته شده: چرخه‌ی یک فیچر، بک‌آپ، رفع اشکال، و بازیابی
کامل بک‌اند.

## ساختن دوباره

بعد از هر تغییری در `guide.html`:

```
npm run docs:pdf
```

خروجی روی همین `gymlic-deploy-guide.pdf` نوشته می‌شود.

به Chrome (یا Edge یا Chromium) نیاز دارد و اسکریپت خودش در مسیرهای معمول
دنبالش می‌گردد. اگر پیدا نکرد:

```
CHROME="<مسیر مرورگر>" node docs/deploy-guide/build.mjs
```

## چرا مرورگر

متن فارسی است. راست‌به‌چپ بودن، چسبیدن حروف، و قطعه‌کدهای چپ‌به‌راست وسط جمله‌ی
فارسی مسئله‌ی حروف‌چینی است که مرورگرها حلش کرده‌اند و کتابخانه‌های PDF نه.

## فونت

`fonts/` وزیرمتن است، کنار فایل نگه داشته شده تا ساخت به اینترنت نیاز نداشته
باشد و خروجی سال دیگر هم همین باشد. در خود PDF جاسازی می‌شود، پس روی هر دستگاهی
درست باز می‌شود.
